00 / 先选目标

组合不是越多越好

Skill 的价值在于让 AI 在合适的时候遵循一套可复用的方法。先装与你近期任务直接相关的一组；需要新能力时再加，避免让技能目录变成另一个没人翻的收藏夹。

05 / 常见问题

先回答四个选择问题

下面的答案与页面结构化数据一致；兼容性和安全结论只写到当前证据能够支持的范围。

Agent Skills 需要全部安装吗？

不需要。先安装当前真实任务所需的一项；只有多个流程确实需要协同时，再考虑使用组合。

中文 Agent Skills 应该怎么选？

先按最终交付选择中文表达、国风视觉、学习与家庭或办公经营，再打开具体 Skill 的方法、案例和边界页核对。

Codex、Claude Code、Cursor 都兼容吗？

本仓库只记录过 Codex 的任务级观察；Claude Code 与 Cursor 仍待本仓库实测。组合也不代表其中所有 Skill 会在一次任务中同时触发。

安装第三方 Skill 前检查什么？

至少检查 SKILL.md、脚本、符号链接、联网、凭据词和文件写删行为。可使用只读扫描器获取人工复核线索，但结果不是安全认证。

没有适合你的组合？

用一个真实、脱敏的中文任务告诉我们缺口；不需要点赞、Star 或先设计解决方案。
