为什么要单独做中式主题

这套主题把中国美学配色与中文排版约束放在同一份 CSS 中。它解决的是行高、中英文间距、标点避头尾、行宽与着重方式等可检查问题，不声称覆盖所有中式视觉传统，也不替代具体项目的字体授权与无障碍复核。

这套主题把中文排版规范写进了基础样式：行高 1.75、行宽 38em、CJK 避头尾、着重号代替斜体。
