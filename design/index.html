8 套中式 DESIGN.md

DESIGN.md 是给 AI 编程工具读的设计系统文档。丢进项目根目录， AI 生成界面时就照着里面的规则来，不用你每次描述一遍。

为什么要专门做中式的？
社区通行的 DESIGN.md 生态里，几十份大厂设计系统， 没有一份处理中文排版——它们的 Typography 章节讲的是字重、字距、x-height， 搬到中文页面上基本不适用。而且很多依赖商业字体（比如 Stripe 用的 Sohne），你本机没有就废了。
✅ 这 8 套不依赖任何商业字体，全用系统自带中文字体； 每套的对比度都是用 WCAG 公式实算的，包括标出不达标的项——下面卡片里能看到。
怎么用
  1. 下面挑一套，点「复制这份 DESIGN.md」
  2. 在项目根目录新建 DESIGN.md，粘贴进去
  3. 告诉你的 AI 编程工具（Claude Code / Codex / Cursor 都行）：
按照项目根目录 DESIGN.md 里的设计规范，实现这个页面

中文排版规则

这一节是 8 套共用的，也是和西文设计系统差别最大的地方。

规则值为什么
行高line-height: 1.75 中文字面率高、没有 x-height 起伏，行高比西文需要更大。1.5 会挤
行宽max-width: 38em 中文每行 30–40 字最舒服。西文常用的 65ch 换算成中文太长
对齐text-align: left 不要用 justify。中文没有词间空格，两端对齐会拉出难看的字距
断行line-break: strict CJK 避头尾：。，、）」不出现在行首，（「不出现在行尾
强调text-emphasis: dot 中文不用斜体。宋体黑体没有真正的意大利体，浏览器做机械倾斜很丑，用着重号
中英间距加一个空格 「使用 AI 工具」比「使用AI工具」易读——这叫盘古之白
字体栈PingFang SC → Microsoft YaHei → Noto Sans CJK SC 分别覆盖 macOS/iOS、Windows、Linux/Android。缺一个就有一批人看到系统默认字体

老实说几句

色值取自本项目自己的 CSS 实现，不代表任何传统色的权威标准——传统色在不同文献里本就有出入。
这 8 套是美学传统的提炼，不是对任何公司视觉的复刻。
没有覆盖数据可视化配色和繁体中文场景（台标/港标字形与断行规则略有不同）。
深色只有「夜宴」一套，其余 7 套是浅色系统。
