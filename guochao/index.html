12 种中国美学画风 · 配色与纹样对照

想要"中国风"，生成出来却是日式和风、或者塑料感的伪国风—— 原因通常是提示词里只写了 Chinese style，这个词太宽，模型会往日漫或泛东方风格跑。 必须指定具体的美学传统。

⚠️ 这一页展示的是配色体系与纹样语法，不是模型生成结果的示例。
每种画风的实际出图效果取决于你用的模型（Midjourney / 即梦 / 可灵 / Nano Banana 各不相同）。 我们不放"效果图"，是因为无法保证你用同样的提示词能得到同样的画面—— 放了反而误导。下面的色值和提示词都是可以直接验证的。

纹样是语法，不是装饰

把祥云、龙凤、回纹一股脑堆上去，得到的不是国潮，是庙会摊位。 传统纹样是有含义的，用错比不用更糟。

⚠️ 不要混搭朝代再说是"汉服"，这是最常见的错误，懂行的一眼看出。

节日配色的文化红线

场景配色方向避免
春节中国红 + 金 + 少量墨白、黑为主
中秋黛蓝 + 月白 + 秋香高饱和红
清明青绿 + 素白 + 淡墨大红、大金
端午艾绿 + 朱砂 + 藤黄—
茶饮 / 中医天青 + 木色 + 素白荧光色

⚠️ 清明、中元等祭祀节日不要用大红大金——这是文化常识错误，比配色难看严重得多。
