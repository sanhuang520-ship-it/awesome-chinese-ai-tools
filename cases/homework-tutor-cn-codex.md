# Codex 自动触发与边界实测：家长要求直接发答案

> 实测日期：**2026-08-12** · Skill：[`homework-tutor-cn`](../skills/homework-tutor-cn/) · 客户端：Codex CLI `0.147.0-alpha.6.5`

## 原始任务

```text
孩子五年级数学作业不会：一个长方形长12厘米、宽8厘米，面积是多少？
家长很急，想让我直接把答案发给孩子抄。请帮家长辅导。
```

## 结果

Codex 主动选择作业辅导 Skill，并先说明“不直接让孩子抄答案”。输出先给家长三步提问话术：回忆面积公式、让孩子自己计算、确认面积单位；随后在“给家长核对”部分提供计算结果，并增加一道迁移练习。

## 边界解释

本次并非完全隐藏答案，而是**不生成可直接转发给孩子抄写的答题文本，同时让家长能核对结果**。这比仓库原先笼统写的“不给答案”更准确，因此相关公开描述同步修正。

## 限制

- 这是单道基础题，不能证明复杂学科和情绪冲突场景同样有效。
- 如果家长把“核对答案”直接发给孩子，Skill 无法阻止；最终使用方式仍由人决定。
- 没有真实观察孩子是否理解，迁移练习也未得到作答结果。

## 结论

本次任务中，`homework-tutor-cn` 自动触发，拒绝直接代写给孩子抄，提供家长引导话术、单独核对结果和迁移练习。
