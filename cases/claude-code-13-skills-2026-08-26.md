# Claude Code 实测：13 个原创 Skill 的发现、加载与任务覆盖

> 实测日期：**2026-08-26** · 客户端：Claude Code（Claude Agent SDK 会话，模型 `claude-opus-5`）
> 对照仓库版本：`main` @ 2026-08-26 · 记录人：本仓库维护流程

## 这份记录能证明什么、不能证明什么

**先说不能证明的，因为它决定了怎么读这张表。**

Codex 那轮的自动触发证据，是 Codex 在提示词从未出现 Skill 名称的情况下，
**自己声明**「我会用『chinese-typography』规范做纯审查」并读取了对应文件。
那是可以从外部观察的第三方行为。

本轮不是。在 Claude Code 中，Skill 通过工具按名称调用，**选择调用哪个 Skill
的模型，与撰写任务措辞、判定结果的模型是同一个**。因此：

> **本轮不构成「自动触发」的独立证据，不与 Codex 那轮同级。**

能够独立观察、不依赖判断的只有两项：Skill 是否出现在客户端会话的可用列表里，
以及是否能被加载、`base directory` 是否正确解析、内容是否完整呈现。
这两项按 ✅ 记；任务覆盖按输出内容判定，证据强度居中；触发不单独记为通过。

其余边界与 Codex 那轮相同：单次、单措辞、单模型版本，不能外推到其他版本或相似措辞。

| Skill | 正文差异 |

| `guofeng-threejs` | **130 → 394 行** |

### 这一条不只是版本卫生问题

`guofeng-threejs` 的本机旧副本，在「其他中式风格的思路」表中把工笔的关键技法
写作 **细线描边（Sobel 后处理）**。本仓库当前版本已改为反向外壳描边，
原因是实测发现 `fwidth(N)` 法线突变检测在光滑有机形体上基本无效
（没有硬转折，`length(fwidth(N))` 全场趋近 0，调阈值无法挽回）。

**即：旧副本仍在分发一条已被本项目自己推翻的技术建议。**

本仓库既有结论「安装不是自动同步」此前只有 Codex 一个客户端的证据，
本轮在 Claude Code 上独立复现，并首次记录到它的实际后果不止于版本不齐，
而是**过时的技术结论会继续被分发给使用者**。

## 2026-08-28 补测：7 个漂移项已在当前版本上重跑

[全局副本追平](skills-cli-global-update-2026-08-28.md)后，7 个漂移项全部重跑，
**任务覆盖 13 / 13**。`guofeng-threejs` 由 ⚠️ 改记 ✅。

### 一个原本以为要等新会话才能验的假设，被推翻了

首轮记录里写着「本次会话加载的是旧副本，改文件也不会改变已加载的内容」，
因此把重测列为「需在新会话进行」。**这个判断是错的。**

实测：更新副本后在**同一会话**调用 `guofeng-threejs`，返回的是 394 行的新版
（含 `fwidth` 实测结论、反向外壳代码、修正后的性能要点第 4 条），不是 130 行的旧版。

Claude Code 的实际行为是：

| 部分 | 何时读取 |
|---|---|
| `description`（frontmatter） | 载入可用 Skill 列表（时机见下方 2026-09-03 更正） |
| `SKILL.md` 正文 | **每次调用时**从磁盘读取 |

> **⚠️ 2026-09-03 更正**：上表原本写的是「`description` 在**会话初始化时**载入」。
> 这个说法不准确。当日在一次进行中的会话里安装了第三方 Skill
> `chinese-git-workflow`（安装时间 18:15，晚于该会话开始时间），
> 它**随即出现在了本会话的可用 Skill 列表中**。
>
> 所以可以确认的只有：**新安装的 Skill 能在同一会话内进入可用列表**（观察到一次）。
> 原表述把「本轮没观察到变化」当成了「机制上不会变化」——
> 和本仓库批评过的那类错误同源：**把一次观察的边界当成了系统的边界**。
>
> 这次更正不影响首轮 13 项的任何判定：那一轮 13 个 description 与仓库逐字节相同，
> 无论何时载入，结论都一样。

这也解释了首轮的处境：13 个 description 逐字节相同，所以触发判断本就不受副本新旧影响；
正文差异只在调用时才体现——也正因如此，改完文件立刻就能重测。

### 重测结果

7 项均在当前版本上命中，且新版内容比旧版更贴合任务：

| Skill | 新版新增的部分是否命中任务 |
|---|---|
| `guofeng-threejs` | 「表内 4 种已全部实现」与反向外壳一节，取代了被推翻的 Sobel 建议 |
| `chinese-web-themes` | 新增「接入现有网站时」6 项上线清单，正对任务里的「现在用 bootstrap」 |
| `homework-tutor-cn` | 「不给答案」改为可操作的「家长核对」分区，并坦承 Skill 无法阻止家长转发 |
| `bookkeeping-cn` `chinese-design-md` `github-readme-cn` `guochao-visual-cn` | 判定与首轮一致，但本次依据的是当前版本 |
