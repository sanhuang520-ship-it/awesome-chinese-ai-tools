# 分学科备课要点

不同学科的教案侧重差别很大，写之前先对照本页。

---

## 语文

**核心**：语言文字运用，不是内容分析。

| 容易犯的错 | 应该怎么做 |
|-----------|-----------|
| 整节课讲课文内容、思想感情 | 落到字词句段的**语言训练** |
| 一上来就分析主旨 | 先读通、读顺，再理解 |
| 只有教师讲 | 保证学生**朗读、批注、书写**的时间 |

**必备环节**：
- 识字写字（低段必须留出 8-10 分钟写字）
- 朗读（形式多样：齐读/指名读/分角色/默读）
- 语言实践（仿写、续写、复述、辩论）

**不同文体侧重**：
- 记叙文 → 理清顺序、抓关键语句、体会表达
- 说明文 → 说明方法、语言准确性
- 古诗文 → 诵读、字词理解、意境想象
- 习作课 → 审题、构思、片段练习、评改

## 数学

**核心**：让学生经历知识的形成过程，不是记结论。

| 容易犯的错 | 应该怎么做 |
|-----------|-----------|
| 直接给公式，然后练习 | 先创设问题情境，让学生**探究、发现** |
| 只讲怎么做 | 讲**为什么这样做**，暴露思维过程 |
| 练习都是同一类型 | 设计**变式**，防止机械模仿 |

**必备环节**：
- 情境导入（联系生活或旧知）
- 自主探究 / 动手操作（尤其小学）
- 算理与算法（先讲理，再讲法）
- 变式练习（正例 + 反例 + 易错题）

**易错点提醒**：备课时要预设学生的**典型错误**，并在教案中写明如何应对。

---

## 英语

**核心**：语言输入 → 输出，创设真实交际情境。

| 容易犯的错 | 应该怎么做 |
|-----------|-----------|
| 逐词讲语法 | 在**语境中**呈现和操练 |
| 只跟读不运用 | 设计 pair work / role play / survey |
| 中文讲解占大半 | 尽量用英语组织课堂，配合肢体和图片 |

**标准流程**（PWP 或 PPP）：
- **Warm-up / Lead-in** → 激活已有语言
- **Presentation** → 呈现新语言（图片、实物、情境）
- **Practice** → 机械操练 → 意义操练
- **Production** → 真实运用（对话、表演、写作）
- **Summary & Homework**

## 科学 / 物理 / 化学 / 生物

**核心**：科学探究，动手做。

| 容易犯的错 | 应该怎么做 |
|-----------|-----------|
| 讲实验、看视频代替做实验 | 能做的一定让学生**动手做** |
| 直接给结论 | 让学生**提出假设 → 设计方案 → 验证 → 得出结论** |
| 忽略安全 | 教案中**明确写出安全注意事项** |

**探究式教学环节**：
1. 提出问题（从现象或矛盾入手）
2. 作出猜想
3. 设计实验（变量控制！）
4. 进行实验、收集证据
5. 分析论证
6. 交流评估

**必写**：实验器材清单、分组方式、安全提示。

---

## 道德与法治 / 历史 / 地理

**核心**：素养导向，联系真实生活与时代背景。

- 用**真实案例、时事材料**，避免空洞说教
- 设计**思辨性问题**，允许学生表达不同看法
- 历史课注意**史料实证**，用材料说话
- 地理课多用**地图、图表**，培养空间思维
- 涉及政策、时事的表述，以现行教材和官方口径为准

---

## 音乐 / 美术 / 体育

**核心**：以活动和体验为主，讲授时间要少。

- **音乐**：听赏 → 模唱 → 表现 → 创造；教案要写清曲目、调式、教学难点（如附点节奏）
- **美术**：欣赏 → 示范 → 创作 → 展评；要留足**创作时间**（不少于 15 分钟）
- **体育**：准备活动 → 技能学习 → 素质练习 → 放松整理；必写**运动负荷预计**和**安全措施**

---

## 通用提醒

1. **课型不同，结构不同**。复习课不能按新授课的模板套。
2. **公开课 ≠ 常规课**。公开课可以设计亮点环节，但常规课要务实、可复制。
3. **时间分配写清楚**。40 分钟的课，环节超过 5 个通常上不完。
4. **每个活动要有产出**。学生做完这个活动，能说出/写出/做出什么？
