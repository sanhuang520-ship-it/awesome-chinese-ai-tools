# 错因分析模板

> 刷题刷不出成绩，是因为**没有分类错因**。同样是错，原因不同，补救方式完全不同。

---

## 错因五分类

| 错因 | 表现 | 补救方式 | 优先级 |
|------|------|---------|--------|
| **概念不清** | 不知道这题在考什么 | 回去补概念，**不要做同类题** | 🔴 最高 |
| **方法不会** | 知道考什么，不知道怎么下手 | 学解法套路 + 3 道同类题 | 🔴 高 |
| **计算/表达失误** | 思路对，过程错 | 限时训练 + 检查习惯 | 🟡 中 |
| **审题错误** | 看漏条件、理解偏 | 强制圈画关键词 | 🟡 中 |
| **纯粹粗心** | 会做，写错了 | 不用补，注意状态 | 🟢 低 |

> **关键**：60% 的人把"概念不清"当成"粗心"，然后继续刷题——这是无效努力。

**填写要求**：

1. **错因必须具体**。写"不会"没有价值，要写"不知道什么时候用换元法"
2. **补救动作要可执行**。写"多练"没用，要写"做 P52 例 3-5 三道题"
3. **复查日期要写**。第 2 天、第 7 天各查一次


## 一个提醒

**错题本最大的坑是"抄一遍就完了"。**

抄题 = 体力活，不产生学习。真正有用的是三件事：

1. **写清错因**（不是抄答案）
2. **隔天重做**（不看答案，能独立做出来才算过）
3. **一周后再查**（这时候还会，才是真会了）

如果时间有限，**只做第 2 件**：隔天重做错题，比抄十本错题本有用。
