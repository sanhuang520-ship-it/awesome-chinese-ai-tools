## 传统色配色方案

### 素雅系（新中式、茶、文人）

| 色名 | 色值 | 说明 |
|------|------|------|
| 月白 | `#EEF0F2` | 极浅蓝白 |
| 天青 | `#8FB8AC` | 雨过天青 |
| 秋香 | `#D9B611` | 沉稳黄 |
| 藕荷 | `#C4A8A8` | 灰调粉 |
| 黛 | `#4A4266` | 青黑 |

> 搭配原则：**3 色以内**，大面积留白，一个点缀色。

### 浓丽系（工笔、敦煌、年画）

| 色名 | 色值 | 说明 |
|------|------|------|
| 朱砂 | `#B93A32` | 正红偏橙 |
| 石青 | `#3A5C8C` | 矿物蓝 |
| 石绿 | `#5A8C6E` | 矿物绿 |
| 藤黄 | `#E8B647` | 明黄 |
| 赭石 | `#8C5A3C` | 土红 |
| 胭脂 | `#9B3A4D` | 深红 |

> 敦煌配色：**土红 + 石青 + 土黄 + 白**，加做旧斑驳质感。

### 国潮系（现代、高饱和）

| 组合 | 色值 | 感觉 |
|------|------|------|
| 中国红 + 金 | `#D02B2B` + `#D4A24C` | 喜庆、贵气 |
| 青花蓝 + 白 | `#2A5CAA` + `#F5F5F0` | 清爽、经典 |
| 墨黑 + 朱砂 | `#1C1C1C` + `#B93A32` | 硬朗、有力 |
| 黛紫 + 秋香 | `#4A4266` + `#D9B611` | 神秘、高级 |

## 场景配色建议

| 场景 | 配色方向 | 避免 |
|------|---------|------|
| 春节 | 中国红 + 金 + 少量墨 | 白、黑为主 |
| 中秋 | 黛蓝 + 月白 + 秋香 | 高饱和红 |
| 清明 | 青绿 + 素白 + 淡墨 | 大红、喜庆色 |
| 端午 | 艾绿 + 朱砂 + 藤黄 | — |
| 茶饮/中医 | 天青 + 木色 + 素白 | 荧光色 |
| 国潮零售 | 高饱和撞色 + 传统纹样 | 灰调 |

> ⚠️ **清明、中元等祭祀节日不要用大红大金**，这是文化常识错误。

## 一个提醒

**纹样和配色是"语法"，不是"装饰"。**

把祥云、龙凤、回纹一股脑堆上去，得到的不是国潮，是庙会摊位。

好的国风设计通常：
1. **一个主纹样**贯穿，其余克制
2. **3 色以内**（传统配色本身就很克制）
3. **留白**是内容的一部分，不是没画完
