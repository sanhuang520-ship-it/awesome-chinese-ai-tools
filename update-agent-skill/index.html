为什么需要更新？

安装是一次复制，不是持续同步。本仓库 8 月 8 日留下的 13 个全局副本，在上游补充元数据和修订内容后，已经与当前仓库 0/13 一致。这不表示当初安装失败，只表示旧副本不能继续证明当前内容。

项目级更新，按四步核对

01 · SCOPE

确认你在项目目录

test -f skills-lock.json && echo "project lock found"

本次结论依赖 CLI 生成的锁文件。没有锁文件时，不要直接套用这个结果。

02 · VERSION

固定并记录 CLI 版本

npx --yes skills@1.5.22 --version

未固定版本的 npx 可能命中旧缓存；未来版本行为也可能改变。

03 · UPDATE

只更新项目副本

npx --yes skills@1.5.22 update -p -y

-p 明确项目范围，-y 跳过范围询问。先确认上游来源可信。

04 · VERIFY

比较完整文件夹

diff -qr skills/<name> .agents/skills/<name>

有 references、demo 或脚本时，只比较 SKILL.md 会漏掉变化。
